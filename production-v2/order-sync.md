# 销售独立订单同步交接

各销售的订单表独立设置在不同多维表格。总订单表以「成交销售」决定归属。程序用飞书记录 ID 对应总表和销售表的同一条订单，显示用的「订单编号」由总表提供。儿童数使用数字字段，填写 0 时保留 0，空值保持为空。

代码按实际字段名核对表头。当前候选里的「订单转态」沿用总表字段名称。每个字段都要绑定到本表的字段 ID；销售表与总表的单选选项应一致。成本、毛利、返佣、退款和返款资料排除在销售同步范围以外。卖价、已支付订金、引流运营属于可选只读业务字段，由授权配置决定是否纳入。

## 只读核对

`orderReadinessReport({ config, client, admin, verifyEffectiveTarget, pageLimit, targetLimit })` 可接受单独维护的私有配置。订单配置包含总 Base、订单数据表、字段 ID、每位销售的独立 Base、表与字段 ID，以及所有者和获授权的管理者。尚未绑定销售表时，可以只核对总表。订单模块不读取派单表的配置来推断目标。

报告只返回计数和错误码。默认每项最多读八页，每页最多 100 条，最多核对八张销售表。遇到分页不完整，报告给出失败原因。订单使用飞书「查询记录」接口，明确发送已授权字段清单；调用方须提供关闭 POST 自动重试的客户端。飞书以文本返回的正常数字按数字核对，儿童数「0」计入已填写。销售表数据读取前会核对直接协作者和有效权限，包括继承权限、只读列、销售能否改状态及能否恢复撤销的副本。核对函数须提供当时有效的权限证据，应用身份由受信任的协作者客户端识别。

## 写入验收

自动复制订单和回写需要单独启用，并提供能在提交时原子核验版本、成交销售和目标授权的写入适配器。飞书通用订单更新接口可直接更新字段，但它的接口协议没有版本或当前成交销售的写入条件。两次读取之间仍存在改派或他人编辑的机会。因此本候选只提供飞书只读适配器，未挂接生产写入，也不创建表或协作者。现有派单数据库及其去重记录无需迁移给订单模块。

写入模块已通过模拟适配器核对改派、旧副本撤销后再分发、跨重启去重、写入结果不明留人工复核、重复订单编号、停续扫描和数据权限。还需要在独立验收环境用两个销售账号核对访问隔离及状态修改权限，并验证原子写入能力后才可接入生产。

如需先在隔离环境试验状态提交，可以单独保留追加式的状态申请。申请绑定总表记录 ID、申请人和本次分配的唯一编号，只采纳与当前负责人和当前分配编号同时相符的申请；记录从甲改派给乙再改回甲时，新分配编号要重新生成。此流程需要另做飞书原生权限和验收。
